# .hermes.md — Hermes-specific project rules (hierarchical)

Hermes-specific rules untuk repo ini. File ini diwarisi dari parent ke subdir sampai git root.
AGENTS.md tetap jadi sumber portable untuk agent lain; jangan duplikasi penuh di sini.

## Build & test (scoped)

- Unit tests nebula: pytest plugins/nebula/tests -q
- Scoped test command per plugin (pola stabil, sinkron CI `.github/workflows/ci.yml`):
  - Syntax/lint: `python -m compileall -q plugins/nebula` (ruff belum terinstall lokal; CI sama pakai compileall). Post-tool hook `post_tool_call_lint.py` fail-open bila ruff tidak ada.
  - Unit tests: `/home/abelion/.local/bin/pytest plugins/nebula/tests -q` — deselect kasus berat bila hardware lambat (lihat AGENTS.md, jangan longgarkan bound): `pytest plugins/nebula/tests -q -k "not pathological"`
  - E2E (butuh host pin): `HERMES_PYTHON=/path/to/pinned/hermes/venv/bin/python HERMES_EXPECTED_COMMIT=9a85916c87d56c2ca00b02fad8918f93ef1816e9 REQUIRE_HERMES_E2E=1 pytest plugins/nebula/e2e -v -rs`
  - Dependency audit (CI): `pip-audit -r <file requirements>` bila ada `requirements*.txt` / `plugin-requirements.txt`
- Jangan jalankan E2E penuh kecuali perlu; E2E butuh HERMES_PYTHON + commit pin 9a85916.
- Scoped per plugin: jalankan hanya tests/ di plugin yang berubah. Plugin baru wajib tambah entri scoped command di sini sebelum checklist dicentang.

## Style

- Cosmic/Latin naming untuk plugin baru (nebula, nova, aurora). Tanpa suffix -abelion.
- Satu plugin satu folder, satu entri hermes.json, docs trio, tests, e2e bila relevan.
- test data synthetic/local-only, tanpa real credentials.
